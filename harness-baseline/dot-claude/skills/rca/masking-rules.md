# 민감정보 마스킹 규칙

RCA 리포트(docs/rca/*.md)를 저장하기 전에 리포트 전체에 적용한다. 원본 로그 파일은 절대 고치지 않는다.

## 가리는 것

| 유형 | 규칙 | 예 |
|---|---|---|
| IP 주소 | 앞 두 옥텟만 남기고 나머지는 x 로 | 10.20.x.x |
| 이메일 | 아이디를 *** 로, 도메인은 유지 | ***@example.com |
| 학생 식별자 | 등장 순서대로 학생A, 학생B … 로 치환. 같은 학생은 끝까지 같은 별칭 | STU-… → 학생A |
| 토큰 · 세션 ID · API 키 · Authorization 헤더 값 | [TOKEN] 으로 | Bearer [TOKEN] |
| 비밀번호 · 접속 문자열 | [SECRET] 으로 | password=[SECRET] |

- 학생 식별자는 지우지 않고 별칭으로 바꾼다. "같은 사용자의 반복 요청"이라는 단서를 잃지 않기 위해서다.

## 가리지 않는 것

- 버전 번호(예: 3.2.1.0)처럼 IP 모양이지만 IP가 아닌 값

## 적용 후

- 리포트 맨 아래에 "마스킹 적용: 유형별 건수" 를 한 줄로 남긴다.
- 어떤 값이 어떤 별칭이 됐는지의 대응표는 파일에 남기지 않는다.

## 확인 명령 (사람이 실행)

```bash
P='([0-9]{1,3}\.){3}[0-9]{1,3}|[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[a-z]{2,}|STU-[0-9]+|Bearer [A-Za-z0-9._-]{8,}'
grep -cE "$P" incident-logs/<시나리오>/*   # 원본에서 0이 아닌 숫자가 나와야 패턴이 유효하다
grep -nE "$P" docs/rca/<시나리오>.md       # 리포트에서는 아무것도 출력되지 않아야 한다
```
