# 배치 · 적재 점검

대상 폴더: $ARGUMENTS (비어 있으면 pipeline-samples/batch-logs)
건수 표: pipeline-samples/datamart-counts.csv

[점검 기준]
1. 실행 여부 — 매일 돌던 job이 없거나 종료 기록이 없으면 이상
2. 중복 실행 — 같은 날 같은 job의 성공 기록이 두 번 이상이면 이상
3. 적재 건수 — 직전 7일 평균에서 30% 넘게 벗어나면 이상. 0건은 무조건 이상
4. 지연 — 소요 시간이 평소의 2배를 넘으면 이상

[규칙]
- 이상마다 근거를 붙인다. 로그는 파일:줄번호, 건수는 CSV의 해당 행
- 로그에 없는 원인은 추측하지 않는다. "확인 필요"로 남긴다
- 평균 · 소요 시간 계산은 명령이나 스크립트로 한다
- 로그를 통째로 읽지 않는다. grep · awk · wc 로 필요한 줄만 뽑는다

[출력]
- 이상이 있으면 docs/batch-check/report.md 에 저장한다(요약 한 줄, 이상 목록 표, 이상 없음 날짜 목록)
  - 요약 한 줄: 점검 기간, 이상 건수
  - 이상 목록 표: 날짜 / job / 점검 항목 / 근거 / 영향 추정 / 다음 확인 사항
- 이상이 없으면 파일을 만들지 않고 "이상 없음" 한 줄만 답한다
